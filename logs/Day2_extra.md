# Day 2 额外补充日志：矩阵 Reshape 拓展练习

## 1. 练习目标
- 脱离教程，凭记忆独立完成一维数组向二维矩阵的转换。
- 验证矩阵乘法 `(2,3)` 乘以 `(3,2)` 的维度变换规则。

## 2. 操作过程
- 新建文件 `day2_extra.py`。
- 创建一维数组 `[1, 2, 3, 4, 5, 6]`。
- 使用 `reshape(2, 3)` 将其转换为 2行3列。
- 使用 `reshape(3, 2)` 将其转换为 3行2列。
- 使用 `np.dot()` 将两者相乘。

## 3. 核心结果
- **成功截图**：![拓展练习成功截图](day2_extra_success.png)
- 终端成功输出：`结果的形状: (2, 2)`
- 证明我彻底理解了矩阵乘法中，中间维度（3）抵消，只留两边维度（2和2）的规则。

## 4. 踩坑与失败记录

### ❌ 报错 1：变量名包含非法字符（SyntaxError）
- **报错现场截图**：![星号变量报错](error_day2_extra_1.png)
- **报错信息**：`SyntaxError: cannot assign to expression here.`
- **报错原因**：我一开始把变量名写成了 `data_2*3`。在 Python 中，`*` 是数学乘号，不能用作变量名，电脑无法识别赋值操作。
- **解决处方**：将变量名改为 `data_2x3`（使用字母 x 代替星号），成功运行。

### ❌ 报错 2：逻辑遗漏导致变量未定义（NameError）
- **报错现场截图**：![漏写乘法报错](error_day2_extra_1.png)
- **报错原因**：在打印结果时，我发现自己忘记写 `result = np.dot(data_2x3, data_3x2)` 这一行运算代码，直接打印 `result`，导致电脑不认识这个变量。
- **解决处方**：补上乘法计算代码，成功输出结果。

## 5. 总结与反思
- 这次练习让我直观感受到了“齿轮咬合”的原理。`(2,3)` 和 `(3,2)` 就像是两个齿轮，中间的 3 咬合后消失了，最后留下来了 2 和 2。以后在 AI 里处理图像特征矩阵时，就会经常用到这种变形。
