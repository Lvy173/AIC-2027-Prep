# Day 3 — 数据处理任务 (Pandas 脏数据清洗)

## 1. 任务说明
使用 `pandas` 对 `train.csv` (Titanic 训练集) 进行基础清洗。具体流程为：均值填充 `Age` 缺失值 → 删除缺失过多的 `Cabin` 列 → 删除所有包含缺失值的脏行。本练习用于掌握真实数据预处理的核心流程。

## 2. 环境与依赖
- Python 3.9+
- pandas 1.3+
- 附安装命令：`pip install pandas`

## 3. 文件说明 (表格)

| 文件 | 类型 | 说明 |
| :--- | :--- | :--- |
| `day3_pandas.py` | 脚本 | 主程序：读取 → 填充 → 删列 → 删缺失行 |
| `code/train.csv` | 数据 | 输入数据 (相对根目录的路径) |
| `Day3.md` | 日志 | 实验日志与报错截图记录 |
| `README.md` | 文档 | 说明文件 |

## 4. 运行方法与预期结果
在项目根目录执行：`python code/day3_pandas.py`

预期结果：
清洗后 `shape` 输出为 `(889, 11)`，各列缺失值统计均输出 0。

## 5. 已知范围与限制
- 本代码采用硬编码相对路径，若在其他层级目录运行需自行调整路径。
- 使用均值填充 `Age` 忽略了年龄的分布特征，可能存在统计偏差。
- 直接删除 `Cabin` 列会损失潜在的有效信息。
- 经实测，Titanic 数据集中 `Embarked` 有 2 个缺失值。代码执行 `dropna()` 后，数据从 891 行精准降至 889 行，证明清洗逻辑准确生效。
